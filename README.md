### 🚀 Featured Projects  
  
#### 🛡️ [Focused — OASIS Platform](https://github.com/SunShineHead/Focused)  
A Python platform (`oasis`, v1.0.0) built on the OASIS architecture, shipping a  
CLI entrypoint (`oasis` → `oasis.cli:main`) and a set of composable **skills**  
(bgm-prompter, excel-generator, github-gem-seeker, internet-skill-finder,  
skill-creator). Requires Python 3.10+.  
`pip install -e .` then run `oasis`.  
  
#### 🎮 [Voxel World — Minecraft Clone](https://gitlab.com/focused2463128/automatic-guacamole)  
A fully playable, browser-based Minecraft clone in pure JavaScript + Canvas 2D  
(no WebGL, no dependencies). Features procedural infinite terrain, 8 block  
types, day/night cycle, physics/collision, flying mode, and full mobile touch  
controls. Just open `index.html`.  
  
#### ▲ [Next.js on Netlify Platform Starter](https://github.com/SunShineHead/next-platform-starter)  
A modern starter on Next.js 16 (App Router), Tailwind CSS, and Netlify Core  
Primitives (Edge Functions, Image CDN, Blob Store). Deployable to Netlify and  
runnable locally via `netlify dev`.  
  
#### 🔥 [Firebase Quickstarts for JavaScript](https://github.com/SunShineHead/quickstart-js)  
A collection of quickstart samples for the Firebase JS SDK covering Auth (email,  
phone, Google/Facebook/Twitter/Microsoft/GitHub, MFA), Realtime Database,  
Firestore, Cloud Functions, Storage, and Messaging.
